# Intervals coaching context

Shared language for the information and operations a coach uses with Intervals.icu.

## Language

**Coach scenario**:
A concrete coaching task, such as analysing a completed session, comparing execution with its plan and history, assessing recovery, reviewing strength work, or changing a planned workout.

**Coach tool completeness**:
Coverage of the agreed coach scenarios with the information and operations needed to complete them, including explicit limits when source evidence is unavailable. The scope is defined by coaching needs, rather than by the number of Intervals.icu operations exposed.
_Avoid_: Full Intervals.icu coverage

**Coach analysis comment**:
A comment on a completed Intervals.icu activity that records the coach's analysis of that session.

**Analysis version**:
One identified version of the coach's analysis of one activity. A later version is a new analysis comment; repeating the publication of the same version refers to its existing publication outcome.

**Coach tool catalogue**:
The declared set of operations available for coach scenarios in each access mode, including the evidence or actions each operation provides.

**Power curve**:
A source-provided series relating effort duration to power, together with the activity, period or prior-work context supplied by Intervals.icu.
